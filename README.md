# Profe Pizarra

Pizarra digital para profesores con widgets de aula, temporizador, detector de ruido, hojas proyectables, fondos y plantillas.

## Publicar en GitHub Pages

1. Sube `index.html` a un repositorio nuevo.
2. En GitHub, entra a `Settings` > `Pages`.
3. En `Build and deployment`, elige `Deploy from a branch`.
4. Selecciona la rama `main` y la carpeta `/root`.
5. Guarda los cambios y espera a que GitHub genere el enlace público.
